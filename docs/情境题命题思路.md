# 家庭学习系统｜生活情境题命题思路（V1.0）

> 本规则从高语桐六年级科学《健康生活》情境卷中提炼，适用于高语桐、高语牧今后的科学、语文、数学、英语练习。属于**出题设计规范**，并非已上传的试卷内容。

## 核心判断

**好的情境题，不是给记忆题套一个生活故事，而是让孩子必须在情境中提取信息、辨认问题、调用知识、作出判断、说明依据。**

题目要让知识成为解决问题所必需的工具，而不是让孩子从题干中的关键词直接猜答案。

## 出题五步法

1. **确定真实知识目标**：先从教材或指定复习范围中选一个要掌握的知识点，明确答案究竟考什么；不悄悄引入超纲事实。
2. **寻找生活中的现象或行动**：例如体检、早餐、运动、春游、时间安排、调查、同伴分歧，不堆砌无关背景。
3. **设置一个需要思考的缺口或冲突**：信息不足、常见误解、反常现象、两个方案的取舍、需要调查验证的判断。不要在题干中同时列出正确答案的分类。
4. **要求给出判断和依据**：不仅问“是什么”，还问“为什么”“仅凭这些信息能否判断”“还需要知道什么”“如何验证”。
5. **让答案落到行动或迁移**：解释原因、提出改进方案、设计调查、判断新情境；必要时允许多个合理方案，并明确评分要点。

## 高语桐卷里值得延续的具体做法

- **数据不能直接代表结论**：两名同学的身高体重数据，需要先计算，再判断“仅凭BMI能否确定谁更健康”，避免把计算结果当成全部结论。
- **从观察走向多种原因**：同龄同学长高速度不同，不能只猜一个原因，要提出可能因素，并思考怎么调查。
- **生活问题中隐藏知识点**：早上没吃饭、上午注意力下降，孩子需要自行联想原因和建议，而不是从题干直接抄出“缺少某种营养”。
- **评价错误判断**：面对“吃饱就等于营养够了”等说法，要求质疑、说明理由、提出调整。
- **把知识用于方案设计**：设计春游午餐盒、规划调查流程；不是背出定义就能答完。
- **比较多个不完善方案**：睡眠、饮食、运动三个角色各有缺口，要求发现缺口和形成综合判断。

## 四个禁止

- **不在题干泄露答案**：例如题目考饮食营养，避免写“连续几天只吃米饭和面条，不吃蔬菜、鸡蛋、牛奶”来暗示对应营养；保留需要孩子推断的部分。
- **不做伪情境题**：删除故事背景后，仍只需机械复述定义的，应重新设计。
- **不加入无关干扰或人为刁难**：情境有必要的细节，但不能依靠语言陷阱制造难度。
- **不把开放推理题误判成唯一标准措辞**：按核心事实、推理链、解释充分程度判定，允许表述不同但科学/逻辑上合理的答案。

## 分年龄设问

- **四年级**：从一个具体现象出发，先“找线索 → 作判断 → 说出理由”，再让孩子提出一个可操作建议。
- **六年级及以上**：可增加“多因素比较 → 信息充分性判断 → 举反例/检验 → 改进方案”两步以上的推理；但仍要有清楚的知识边界。
- **跨学科迁移**：数学强调为什么选这一算法及信息是否足够；语文强调人物意图、文中证据、隐含意义；英语强调在交际情境中选择或表达恰当信息；科学强调观察、因果、证据和验证。

## 每道情境题的出题自检

- 如果去掉生活故事，是否还需要真正判断？如果不需要，重新出题。
- 题干是否把答案直接说出来了？
- 孩子必须处理的关键线索是什么？
- 错误选项或常见错误判断为什么有迷惑性？
- 参考答案能否解释**理由**，而不只是列正确词？
- 是否只考指定范围，是否适配孩子年级？
- 如果孩子说出另一种有依据的合理答案，评分规则是否容纳？

## 与三轮巩固机制协同

**第1轮全部做；第2轮只做第1轮未掌握的题；第3轮只做前两轮仍未掌握的题。** 每轮仅批改当轮实际作答题；已确认掌握的题无需重复做，仍保留其最初掌握轮次。每题显示「待巩固／第1轮掌握／第2轮掌握／第3轮掌握／三轮仍需巩固」等状态，可开启「只看待巩固题」。

旧卷原件、历史数据、原始答题记录一律保留，功能迭代不得覆盖已形成的数据。

---

**一句话准则：以生活现象制造需要判断的问题，让孩子凭知识和证据完成解释，而不是从题干里寻找现成答案。**
